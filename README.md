# Valcourt & Marchon Architectes – démo

**Site de démonstration – entreprise fictive.** Cabinet d'architectes imaginaire (Lyon 7e), site de 3 pages : accueil, projets, agence.

- **Stack :** HTML / CSS / JavaScript, sans framework ni dépendance. Hébergement Cloudflare (Workers, assets statiques).
- **Contenu :** tout le texte vit dans `data.js`, injecté dans les pages par `render.js`.
- **Site en ligne :** https://demo-architectes.atelier-requena.workers.dev
- **En local :** `python3 -m http.server` à la racine, puis http://localhost:8000
- **Crédits photo et polices :** voir [CREDITS.md](CREDITS.md).

Le cabinet, ses projets, son équipe et ses coordonnées sont fictifs. Le site est volontairement non indexé (`noindex`).
